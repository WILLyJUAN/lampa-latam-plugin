# Контракт провайдера

Каждый адаптер возвращает массив объектов следующего вида:

```js
{
  provider: 'Имя исходного провайдера',
  title: 'Название источника',
  language: 'Latino',
  audioTracks: [{ id: 'latino', name: 'Latino', language: 'Latino' }],
  quality: '720p',
  url: 'https://…/master.m3u8',
  headers: { Referer: 'https://…', 'User-Agent': '…' },
  isEmbed: false,
  sourceUrl: 'https://страница-источник/'
}
```

`latam.js` не удаляет `headers` и не подменяет URL. Перед запуском он проверяет их против возможностей Samsung AVPlay. Поток с непустыми необходимыми заголовками не передаётся в `Lampa.Player.play`, потому что Tizen API Lampa принимает только URL.

Выбор выполняется в два шага: сначала объявленная аудиодорожка (язык), затем источник/качество. Если HLS содержит несколько встроенных дорожек, после успешного открытия их дополнительно показывает штатный экран дорожек Lampa.

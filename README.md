# Lampa LATAM — технический адаптер для Samsung Tizen

Это однофайловый JavaScript‑плагин Lampa с консервативной проверкой совместимости источников. Он создан только для анализа и адаптации HTTP‑логики из указанных репозиториев; он не добавляет TorrServer, P2P, Debrid, собственный каталог или новые сайты.

## Что в репозитории

```
lampa-latam-plugin/
├── latam.js                 # самодостаточный URL для установки в Lampa
├── providers/
│   ├── repelishd.js          # читаемая версия проверенного HTTP-адаптера
│   └── CONTRACT.md           # формат результата провайдера
├── README.md
└── TEST_RESULTS.md
```

`latam.js` добавляет на карточку Lampa кнопку **LATAM**, извлекает исходные поля `provider`, `title`, `language`, `audioTracks`, `quality`, `url` и `headers`, а затем даёт выбрать язык и источник. Воспроизведение разрешается только для прямого HTTPS HLS/MP4 без обязательных заголовков. Это ограничение необходимо для Samsung Tizen: используемый Lampa AVPlay вызывает `webapis.avplay.open(url)` и не умеет передавать `Referer`, `User-Agent`, `Cookie` или произвольные HTTP‑заголовки.

## Состояние адаптеров

Реализован и подключён HTTP‑адаптер **RePelisHD** из `latinuvio-V2`. Он корректно сохраняет все возвращаемые сведения, включая язык, источник, качество, HLS URL и обязательные заголовки. На Tizen его результаты автоматически блокируются перед воспроизведением: проверка показала, что итоговый HLS требует `Referer` и `User-Agent`.

Это намеренное поведение: плагин не «успешно» запускает поток, который AVPlay вернёт с `403`.

## Результат аудита исходников

| Репозиторий | Результат | Причина |
| --- | --- | --- |
| `latinokodi/latinuvio-V2` | HTTP‑провайдеры изучены; добавлен RePelisHD как эталон адаптера | В его manifest 35 провайдеров; все 35 возвращают playback headers, а 23 требуют Node‑модули. На Tizen нельзя применить требуемые заголовки при открытии AVPlay. |
| `yoruix/nuvio-providers` | исключён | В проверенной ветке `template` manifest содержит только `template-provider`, без рабочего источника для переноса. Сам проект лицензирован GPL‑3.0. |
| `roberthgnz/cinecalidad-stremio-addon` | исключён | Это Node/Express/Stremio addon c SQLite; потоковый обработчик обрабатывает magnet/torrent и download links. Это противоречит запрету на P2P/TorrServer и требует backend. |

У `latinuvio-V2` в скачанном снимке нет файла `LICENSE`; поэтому в этом проекте не копируется его исходный код. `providers/repelishd.js` — самостоятельная компактная реализация только проверенного HTTP‑контракта, с указанием источника поведения.

## Установка

После публикации откройте в Lampa **Настройки → Плагины → Добавить плагин** и вставьте прямой HTTPS URL raw‑файла `latam.js`:

```
https://raw.githubusercontent.com/WILLyJUAN/lampa-latam-plugin/main/latam.js
```

Опубликованная ссылка: [latam.js](https://raw.githubusercontent.com/WILLyJUAN/lampa-latam-plugin/main/latam.js).

## Ограничения, которые нельзя устранить внутри плагина

- Нельзя задать HTTP‑заголовки AVPlay через `Lampa.Player.play`.
- Нельзя безопасно выдать iframe как видеопоток.
- Плагин не запускает невалидированные `m3u8`, не подменяет URL прокси и не применяет обходы доступа.
- Доступность сторонних источников меняется; результаты проверки относятся к указанным upstream‑ревизиям и дате в `TEST_RESULTS.md`.
